# Git & GitHub Basics

## Project Description

This project demonstrates the basic Git and GitHub workflow. It includes creating a repository, cloning it to the local system, adding project files, committing changes, and pushing the changes to GitHub.

## Objectives

* Install and verify Git.
* Create a GitHub repository.
* Clone the repository to the local system.
* Add project files.
* Stage files using Git.
* Create a commit.
* Push changes to GitHub.
* Verify the uploaded files on GitHub.

## Technologies Used

* Git
* GitHub
* HTML
* CSS

## Git Commands Used

```bash
git --version
git clone
git status
git add .
git commit -m "Initial project commit"
git push origin main
```

## Conclusion

The basic Git and GitHub workflow was successfully performed. The project files were added to the local repository, committed using Git, and uploaded to GitHub.
